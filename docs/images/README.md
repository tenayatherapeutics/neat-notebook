# Image provenance

The project icon, packaged at `neat_notebook/tenaya-icon.png`, is the unmodified
32 × 32 PNG supplied by Tenaya Therapeutics at
<https://www.tenayatherapeutics.com/favicon-32x32.png>. It identifies the
Tenaya Therapeutics project. The software license
does not grant rights to Tenaya Therapeutics trademarks.

`desktop-light.png`, `desktop-dark.png`, and `mobile.png` are screenshots of
Neat Notebook using synthetic test notebooks. They contain no patient or
proprietary research data.
